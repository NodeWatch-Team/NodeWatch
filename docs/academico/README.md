# Material acadêmico

Registros das entregas da disciplina, guardados como foram escritos. Eles descrevem o projeto na data de cada
entrega: caminhos, comandos e partes do sistema citados ali podem ter mudado ou saído depois (por exemplo, a
interface antiga, a CLI de grafos e o módulo de telemetria de rede). Para o estado atual, veja o
[README](../../README.md).
